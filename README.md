# English

## 📂 Project Structure

```text
jaimo/
├── .github/
│   └── workflows/
│       └── publish.yml         # GitHub Actions Automated Release Workflow
├── src/
│   └── jaimo/
│       ├── __init__.py         # Package Entry Points and Directories
│       ├── core.py             # Core Logic / Main Class Encapsulation
│       └── num.py              # Numerical methods module
├── tests/
│   └── test_core.py            # Main test
├── .gitignore                  # Git Ignore Files
├── LICENSE                     # MIT Open Source License
├── README.md                   # Project Specification Document
└── pyproject.toml              # Project Metadata and Packaging Configuration Files
```

## 📦 Installation

You can install Jaimo via PyPI or directly from the GitHub source repository.

### Method 1: Install from PyPI (Recommended for Users)

```bash
pip install jaimo
```

### Method 2: Install from Source (Recommended for Developers)

```bash
git clone https://github.com/jaimocore/jaimo.git
```

```bash
cd jaimo
```

```bash
pip install -e .
```
